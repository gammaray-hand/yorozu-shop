# よろず便利商店｜PR自動一次監査フロー

## 目的
Web本店の変更時に、オーナーが毎回レビュー依頼を出さなくても、PR作成をきっかけにAIが自動で一次監査を行う。

## 現在の流れ
1. `gammaray-hand/yorozu-shop` にPull Requestを作成する。
2. ChatGPT Workの「よろずPR確認」が新規PRを検知する。
3. PRの説明・変更ファイル・差分・利用可能なテスト結果を確認する。
4. 次の観点を日本語で報告する。
   - 変更目的と内容
   - 不具合・表示崩れ・リンク切れ・セキュリティ上のリスク
   - 既存機能への影響
   - 残る確認事項
   - マージ可否の判断材料
5. レビュー結果は再利用できるMarkdown成果物として残すことを試験する。

## 権限境界
自動監査は一次確認までとし、GitHubへのコメント投稿、レビュー送信、コード変更、マージは自動では行わない。

## 運用意図
「情報は繋ぐ。権限は分ける。」を基本とし、オーナーを伝書鳩にせず、最終判断だけ人間側へ残す。
