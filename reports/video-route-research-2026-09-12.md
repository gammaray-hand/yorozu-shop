# 静止画→動画化ルート実地調査（2026-09-12）

## 結論

- Work内部だけで静止画から動画を生成する経路: **NO（現環境）**
  - 利用可能な生成機能は静止画の生成・編集であり、動画生成ツールは確認できなかった。
  - 既存MP4の検査・編集・再エンコードは可能だが、これは静止画から新しい動きを生成する機能ではない。
- 外部サービスをブラウザ操作する経路: **条件付きYES**
  - Runway、Pika、LumaはいずれもWorkブラウザから公式サイトへ到達できた。
  - RunwayとPikaは画像入力・プロンプト入力・生成開始のUIまで確認。LumaはアプリURLからサインアップ画面へ遷移した。
  - 実生成、完成MP4のダウンロード、Workへの回収は、外部アカウントでのログイン後に改めて実機確認が必要。

## 推奨ルート

### 第1候補: Pika Web

人間操作を最小化しつつ、無料・商用利用・透かしなしという条件を公式料金ページ上で同時に満たす候補。

- image-to-video: 対応。Pika 2.5は5秒/10秒。
- 無料枠: Basic $0、月80 video credits。480pの5秒は12 credits、10秒は24 credits。
- 商用利用: 料金ページのBasic欄にCommercial useと記載。
- 透かし: Basic欄にDownload videos with no watermarkと記載。
- 縦動画: 公開トップ画面では比率指定を確認できず、**未確認**。API側の一部モデルは9:16対応だが、Pika 2.5 Webの保証とは扱わない。
- 構図維持: image-to-videoとPikaframes（先頭/末尾フレーム）を公式に提供。ただし今回の完成静止画での保持品質は未検証。
- ログイン: 必須。公開画面でプロンプトを入力してGenerateを押すとログイン画面へ移動した。
- 決済情報: 無料枠の範囲ではカード入力を求める地点まで進んでいない。アカウント作成は未実施。
- Work操作: 公開トップのプロンプト、Attach image、5s、モデル、Generateまで到達。ログイン後の生成・MP4取得は未確認。

公式: [料金](https://pika.art/pricing) / [FAQ](https://pika.art/faq) / [利用規約](https://pika.art/terms-of-service)

### 第2候補: Runway Web

公式規約上、出力の商用利用制限がなく、制作・編集機能がまとまっている候補。

- image-to-video: 対応。公開生成画面で参照画像追加、動画モデル、タイムライン編集への導線を確認。
- 無料枠: 公式料金ページはFree $0、125 one-time credits。一方、実機のサインアップダイアログは「500 credits、カード不要」と表示しており不一致。登録時表示を正とし再確認が必要。
- 商用利用: 利用規約（2026-05-11更新）は、規約順守を条件に出力の商用利用を制限しないと明記。
- 透かし: Standard以上はno watermarksと明記。Freeの透かし有無は料金ページで明示されず、**未確認**。
- 縦動画: 公式公開情報だけでは当該無料モデルの9:16出力を確定できず、**未確認**。
- 秒数: Gen-4.5は料金表上5秒単位。モデルにより4秒/5秒など異なる。
- 構図維持: 参照画像を使う動画生成導線あり。ただし今回の完成静止画での保持品質は未検証。
- ログイン: 必須。プロンプト送信後に無料サインアップ要求。カード不要と表示。
- Work操作: ゲスト生成画面、参照追加、プロンプト、動画モデル、タイムライン導線まで到達。ログイン後の生成・MP4取得は未確認。

公式: [料金](https://runway.com/pricing) / [利用規約](https://runway.com/terms-of-use) / [生成画面](https://app.runwayml.com/)

### 第3候補: Luma Dream Machine / Luma App

9:16を含むフォーマット展開と制作工程統合が公式に案内されるが、商用利用には有料プランが必要。

- image-to-video: 対応。
- 無料/有料: 公式ライセンス案内ではFree/Liteは非商用・透かし付き。PlusはWeb $29.99/月、商用利用可・透かしなし。
- 商用利用: Plus、Unlimited、Enterpriseで可。Free/Liteは不可。
- 縦動画: 公式記事で1:1、9:16、16:9の複数フォーマット展開を案内。
- 秒数: 現行アプリのモデル別秒数はログイン前に確定できず、**未確認**。
- 構図維持: 公式は共有コンテキストや連続性を訴求するが、今回の静止画での保持品質は未検証。
- ログイン: 必須。アプリURLはサインアップへ直行し、メールまたはGoogle/Apple連携が必要。
- 課金: Instagram等の商用利用には最低Plusが必要なため、今回の「課金しない」条件では実生成対象外。
- Work操作: サインアップ画面まで到達。ログイン後の生成・MP4取得は未確認。

公式: [ライセンス](https://lumalabs.ai/learning-hub/licensing) / [料金・契約](https://lumalabs.ai/learning-hub/payments-subscriptions) / [Luma App](https://lumalabs.ai/app)

## オーナー本人の操作が必要な箇所

1. 採用サービスのアカウント作成または既存アカウントへのログイン。
2. 新規アカウント作成時の利用規約・プライバシーポリシーへの同意判断。
3. Runwayの場合はFree枠の実際の付与creditsと透かし条件の最終確認。
4. Pikaの場合はBasicの商用利用・透かしなし表示が登録後の契約画面でも維持されているか確認。
5. 有料プランを使う場合の契約・決済（今回は未実施）。

## 完成静止画受領後にWorkが担当できる範囲

外部アカウントが利用可能で、ログイン済みブラウザが提供され、素材の外部アップロードが明示的に許可された後であれば、次を担当できる可能性が高い。

1. 完成静止画を対象サービスへアップロード。
2. motion prompt、秒数、モデル、縦比率の設定。
3. 生成結果の確認と必要な再生成。
4. MP4のダウンロード。
5. 9:16への整形、尺調整、BGM・字幕等の編集。
6. 解像度、fps、コーデック、音量、全編デコードの検査。
7. 最終MP4の返却。

ただし、ログイン後の生成とダウンロードは今回未確認なので、初回は小さな無関係テスト素材で一連の回収まで検証する必要がある。
