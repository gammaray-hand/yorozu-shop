# 総司令発注｜森・店入口Reel用 9:16 First Frame 制作

日付: 2026-09-14

## 目的
今回だけ画像を作って終わるのではなく、今後Workが再現できる「Reel用静止画 → Runway画像動画化」の標準経路を作るための初回実作業。

現在のRunway実機確認で、4:3の森画像をGen-4 Turboへ入れると9:16出力時にクロップ警告が出た。最終用途はInstagram Reel 9:16なので、4:3を無理にクロップせず、最初から9:16のFirst Frame素材を制作する。

## 参照元
オーナーが使用許可済みの森画像。内容は、夕暮れ〜夜の森、手前から奥へ続く細い道、奥に暖色の灯りがともる小さな木造店。店へ向かって歩いていく主観映像の元絵として使う。

※参照画像そのものが作業環境から取得できない場合は、勝手に別画像で代替して完了扱いにしない。取得不能を明示して停止すること。

## 制作条件
- 出力静止画は最初から 9:16 縦構図。
- Instagram ReelのFirst Frameとして使える解像度を確保する。
- 元の森・道・暖色の小さな店という景色と雰囲気を維持する。
- 単純な4:3画像の中央クロップではなく、9:16として自然に成立する縦構図に再構成する。
- 画面下側〜中央に道を十分残し、カメラが前進して店へ近づくImage-to-Videoに適した奥行きを作る。
- 店は奥に置き、最初から画面を占有しすぎない。森の中で店を見つけて近づく体験を残す。
- 人物、動物、文字、ロゴ、看板文字、新しい目立つ物体を勝手に追加しない。
- 過度にファンタジー化・高級ロッジ化・派手な発光をしない。現実寄りで静かな夕暮れ〜夜の森。
- 既存の店・森を『公式設定』として固定する意図はない。今回の入口Reel用素材として制作する。

## 次工程を前提にする
完成画像はRunwayの Gen-4 Turbo Image-to-Video の First Video Frame として使う予定。
現時点の実機候補設定は 9:16 / 720p / 5秒 / Audioなし。動画側では主観カメラが森の道を滑らかに前進し、店へ近づく単一動作を与える。

## 完了条件
1. 9:16静止画が実際に作成され、オーナーが確認できる形で成果物が提示される。
2. 使用した制作方法・主要指示・出力サイズを報告する。
3. 次回Workが同種素材を再現できるよう、成功した制作手順を簡潔に残す。
4. 画像を作れない／参照元を取得できない場合は、できたふりをせず理由を明示して停止する。
5. Runway生成やInstagram公開には進まない。今回はFirst Frame素材制作まで。

## 人間確認
完成した9:16画像は、Runwayへ投入する前にオーナーと総司令が一度だけ確認する。ここが人間判断境界。
